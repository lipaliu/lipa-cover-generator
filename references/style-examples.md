## 色彩分析实战案例

### 暗调室内（办公室/咖啡馆/夜景）
- 明度：暗 → 用高亮色
- 首选：B1明黄+白、B2纯白+灰、B4荧光绿+白、B7暖橙+白
- 描边：黑色描边增强可读性

### 户外明亮（蓝天/海边/白墙）
- 明度：亮 → 用深色重色
- 首选：B6深黑+灰、B11深蓝+金、B12砖红+米白
- 或用高饱和色：B5珊瑚粉、B3冰蓝（需加白色描边）

### 暖调场景（黄昏/暖光/木质）
- 色温：暖 → 补色用冷色
- 首选：B3冰蓝+白、B8薄荷绿+深绿
- 或顺色：B1明黄（同暖但拉开明度）

### 冷调场景（蓝调/灰调/现代）
- 色温：冷 → 补色用暖色
- 首选：B7暖橙+白、B5珊瑚粉+白、B1明黄+白

### 高饱和彩色（霓虹/彩墙/鲜艳服装）
- 饱和度：高 → 用补色或黑白
- 首选：B6深黑+灰、B2纯白+灰、或取色环对面

## 排版选择逻辑

```
人物偏右 → C4左对齐阶梯 / C7竖排（左侧）
人物偏左 → C5右对齐阶梯 / C7竖排（右侧）
人物居中 → C1顶部 / C2底部 / C6对角 / C14满铺
人物在下方 → C1顶部 / C14满铺
人物在上方 → C2底部
人物全身 → C8环绕 / C11散落
主体小/远景 → C3居中霸屏 / C14满铺
信息量大 → C9分区色块 / C10杂志多层
```

## 经典组合示例（从案例中提炼）

### 组合1：情绪冲击型
- A1狂野书法 + B1明黄 + C3居中霸屏 + D7描边阴影 + E4倾斜+E5重叠
- 效果：文字巨大倾斜，墨迹飞溅，黄色字黑色描边，极强冲击力

### 组合2：干货知识型
- A2超粗黑体 + B3冰蓝 + C1顶部横排 + D1色块底框 + E1关键词放大
- 效果：工整有力，蓝色大字顶部排列，关键词特别大，标签有色块

### 组合3：文艺Vlog型
- A3手写 + B2纯白 + C11散落式 + D3英文装饰+D10 REC标记 + E9中英混排
- 效果：手写白字散落画面，配小英文装饰，REC标记，随性自然

### 组合4：电影高级型
- A6电影衬线 + B2纯白+B11金 + C2底部压字 + D2渐变蒙版 + E11双行拆分
- 效果：底部深色渐变，白色衬线大字，金色副标题，电影海报感

### 组合5：活泼可爱型
- A5圆润卡通 + B4荧光绿 + C11散落式 + D4手绘标注+D8贴纸 + E8大小混排
- 效果：圆润绿色字散落画面，手绘箭头圈圈，贴纸效果，活泼可爱

### 组合6：杂志专业型
- A7杂志标题 + B6深黑 + C10杂志多层 + D5引号+D3英文 + E1关键词放大+E2变色
- 效果：黑色杂志体，多层信息排列，引号装饰，关键词红色放大

### 组合7：综艺热闹型
- A9综艺立体 + B9渐变双色 + C3居中霸屏 + D7描边阴影+D12几何色块 + E5重叠+E7出血
- 效果：3D立体渐变大字铺满画面，多层描边，字出画面边缘

### 组合8：极简高级型
- A10纤细文艺 + B2纯白 + C7竖排 + D13无装饰 + E10竖横混排
- 效果：细白字竖排，大量留白，极简高级，安静有力

### 组合9：街头态度型
- A8马克笔 + B7暖橙 + C4左对齐阶梯 + D4手绘标注 + E4倾斜+E8大小混排
- 效果：马克笔橙色字左对齐阶梯排列，手绘箭头，倾斜有态度

### 组合10：现代设计型
- A11描边空心 + B10描边撞色 + C6对角分布 + D12几何色块 + E1关键词放大
- 效果：空心描边字对角分布，几何色块点缀，现代设计感强
