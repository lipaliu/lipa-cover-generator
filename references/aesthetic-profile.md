# 审美基底画像（Aesthetic Profile）

> 这是本产品「审美基底」的人类可读定义。它**不是**被代码直接读取的文件，而是
> `server/design-matrix.js`（权重）与 `server/prompts.js`（AESTHETIC CURATION 指令）
> 背后的设计依据。每次调整权重/指令，都应回到这份画像对齐。
>
> 来源素材：
> - 127 张创作者亲自挑选的小红书/抖音封面（`xhs_covers_text_layout`，明亮活力出片感）
> - 80 款剪映「高级感封面标题预设」（高级排版语言：大字 + 小英文副标 + 序号 + 描边）
> - aya 套（知识/教程）：超粗黑体顶天立地 + 厚描边 + 关键词色块/圆标 + 序号 + 像素/手绘/emoji 小装饰 + 高饱和撞色，活人感
> - ruiren 套（生活/美食/Vlog，全集 587 张，用 gpt-4o-mini 视觉抽样统计得到的真实分布）：
>   **多图拼贴宫格 86%**（2/3/4 格，绝对招牌）、**手写花体英文标题 49%**（Mini Vlog / Daily Vlog 那种飘在拼贴上的优雅英文花体）、
>   配色以**暖橙 + 黑白**为主（偏暖偏柔，非高饱和撞色）、情绪**活力 56% + 温暖治愈 31%**、装饰偏干净（73% 无，色块条/emoji/星星点缀）、多数无副标。
>   一句话：**「多宫格拼贴 + 中间手写花体英文标题」的清新生活流**。
>   另有一支「知识攻略」分支：超粗黑体顶天立地 + meme 表情包 + 虚线框抠图（与 aya 教程风一致）。

## 重心原则（关键）

**设计元素（花字、字体、排版、装饰）来自上面这套审美库的排列组合 —— 这是主力、是重点。**
标题语义只作**轻量氛围参考**（优先级低）：它最多决定明亮/暗黑这种调性，**代表不了具体元素**。
所以默认走审美矩阵主导（`FAST_DIRECT_MODE=1`），不让 gpt-4o 读标题来主导判断元素（避免本末倒置）。

## 一句话定位

**明亮、阳光、有活力的真实照片　×　高级感的大字排版。**

不是暗黑奢华，不是廉价少女气，而是「出片感 + 编辑级排版」。

## 内容场景（IP 调性）

旅行 / 骑行 / 运动 / Vlog / 摄影教学 / 个人成长。主体多为真实人物（创作者本人）在
户外、晴天、城市或自然中。**永远保留原片**，只叠加文字和轻装饰。

## 七维审美偏好（喂给设计矩阵）

| 维度 | 强偏好（weight 3） | 降权/避免 |
|---|---|---|
| **A 字体** | 黑体、极粗体、书法/毛笔飞白、衬线英文、极细体、无衬线英文（白色描边大写）、手写体/钢笔手写（点缀层） | 霓虹体↓、金属/奢华字↓、像素/蜡笔/漫画（禁用） |
| **B 布局** | 居中霸屏、顶部横幅、左上对齐、分散四角/拼贴、网格多宫格、上下分割、底部横条、环绕主体 | 圆形环绕↓ |
| **C 效果** | 纯色填充（白/黄）、描边镂空（厚描边）、色块遮罩、撕纸/拼贴、贴纸白边抠图 | 霓虹发光↓、金属质感↓、玻璃折射↓ |

## 招牌排版套路（House Style，强烈复现）

来自 80 款预设 + 127 张图的高频组合，生成时应高概率出现：

1. **超大主标题**（黑体/极粗/书法），占画面宽度 60%+。
2. **小英文 / 拼音副标题**贴在主标题旁（如 `DAO YU SEN LIN`、`Daily Vlog`、`cycling with lemon`）。
3. **小杂志标记**：序号 `01` / `VOL.01` / `NO.01`、`®` `™` `(C)2025`、`#话题`、`Co.,Ltd.`。
4. **白色厚描边 / 抠图白边**让文字从复杂照片里跳出来。
5. **手写花体**做一行点缀，与硬朗大字形成对比（solotrip / Half / Ride into spring）。
6. **拼贴 / 多宫格**：抠图人物 + 多张小图 + 白描边，编辑级排版。

## 红线（绝不出现）

- 不生成 AI 假人 / 假脸；不先做空背景再贴字。
- 不走暗黑、奢华金、赛博霓虹、少女粉嫩的整体基调（除非用户显式要求）。
- 竖版不得整体调色 / 加滤镜，只在文字与装饰处改动像素。

## 批次 4：大牌极简风 / 电影节海报（xhs_5ef222d300，31 张，2026-07 全量入库）

创作者定位：影评 / 书评 / 播客 / 歌单推荐类知识文化内容（谈话头像 + 剧照 + 黑白艺术照）。

签名模式（已入矩阵，平等参与随机）：
- **关键词换色（C16）**：一句标题里 1-2 个关键词换成亮黄/绿/品红/红，其余白或黑；全句字距拉宽。出现率最高的招牌。
- **角落定位点（E21）**：四角小色点（蓝/绿/黄/品红），像印刷定位标。
- **海报环绕拼贴（E22）**：电影海报/专辑封/书封环绕人物漂浮——推荐类内容的"证据拼贴"。
- **引号书名号装饰（E23）**：「」《》放大作图形元素，常单独换色。
- **电影节海报·大牌极简氛围（G11）**：暗调书房/剧照底 + 细字重优雅字体 + 大字距 + 少量锐利强调色，像艺术影展海报或大牌广告。
- 高频复用现有条目：A3宋体 / A7衬线英文 / A12极细体、B12上下分割（剧照分屏+中缝字带+EPISODE期数）、C7色块遮罩（红条衬底）、E15数字编号、D14单色+点缀、D1黑白（黑白艺术照+彩字）。

关键词联动：标题含 影评/观影/电影/书评/文学/播客/歌单 时，C/E/G 维优先从上述新条目中抽。

## 批次 5：小Lin（xhs_5abf90244e，363 张，2026-07-25 全量入库；已逐张扫遍 0001–0363）

创作者「小Lin」= 财经/宏观/科技新闻解说号。这是**唯一"要读懂标题含义去配场景"的风格**（G12），与总库"别解读标题"规则相反。

**核心签名（绝大多数）：**
1. **主体抠图**：把小Lin本人从底图抠出、去掉原背景，作前景人物（多为下半居中或偏一侧、半身、略压底边）。
2. **按标题合成戏剧化匹配场景**：主体身后合成 2–5 个与标题主题直接匹配的真实道具/人物/场景，主体+背景浑然一体、相辅相成。映射举例：财经→钞票堆/K线涨跌/金银条/银行门脸/城市天际线；某国→国旗+相关领袖民众；贸易战/谈判→双方国旗+代表人物对峙；科技AI→芯片/服务器/机器人/发光电路/公司logo；奥运体育→火炬/白鸽/体育场/奖牌/足球；药价→药丸+价签；养老→老人人群；品牌→该品牌logo与产品。
3. **超大方正粗黑标题**（黑体/极粗黑），占顶部约40%，一眼看懂；**字体不重要，"方+实+简洁+清晰"最重要**；厚白或黑描边+立体阴影。
4. **关键词描金换色**：1–2 关键字金/黄，其余白；常配 ?! ？ 「」 增强戏剧感。
5. **顶部英文小标**（标题的英文翻译，衬线或压缩体）。
6. 常见小黄圆角标签（完整版/为什么?/期数(1)(2)(下)）。背景配色随主题（黑金财经、红旗政经、绿场、紫科技…）。

**变体（少数，也在库内）：**
- 双人访谈：小Lin+嘉宾对坐/并排，蓝/紫科技调，"小Lin × XXX" + 品牌logo（腾讯新闻·奔驰、Duolingo…）。
- 纯文字预告/招聘页：亮黄底 + 荧光笔高亮词 + ▶▶▶ 箭头。
- 插画/漫画风拼贴；圆形头像九宫格环绕（我的AI同事）；logo卡片墙环绕（AI混战）；简约纯色板抠图+简单道具（私募风投）；实拍采访花絮（LinkedIn）。

**落地**：G12「小Lin」整体风格；选中它 → prompts 注入抠图+图文匹配+方正粗黑+描金+顶部英文的专属指令（覆盖"别解读标题"规则、放开像素保护）；矩阵自动偏向 A4/A13/A8 字体、C16/C2/C7 效果、E22/E21/E23/E15 装饰。
