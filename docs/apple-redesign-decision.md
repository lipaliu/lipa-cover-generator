## v2（同一 artifact，版本 2）
- 背景改为自研 WebGL 着色器 shader.js：沿缓慢扭曲场的等值线生成光滑液体管，管内横向油膜色带（蓝/青/珍珠白/黄/橙/品红/紫），高光、珍珠光泽、颗粒；持续流动，鼠标移动会搅动液体。不再使用原仓库任何图片，素材版权问题消除。无 WebGL 时退回同款静态图 assets/bg-oil.jpg。
- 底部切换改为本背景的五种配色：油膜（默认）、珍珠、日落、深海、银；缩略图实时从着色器渲染并自动裁取液体最多的区域。
- 修复：玻璃滤镜层原为行内 span，宽高未生效，导致此前版本的折射和浅色按钮白底实际没有渲染；改为块级后折射、深浅按钮均与原站一致。
- 是否通过：未通过。反馈：要「气泡」、能动、背景不要纯黑，流动的玻璃质感 + 毛玻璃，整个背景流动，带粒子或水波纹。
- 中间试过肥皂泡版本，用户纠正：「类似流动这种，不是实体的气泡，更不是肥皂泡」，参考图为 macOS Tahoe 壁纸（斜向流动的蓝色玻璃波浪、奶油色天空、景深虚化）和一张 iOS 风层叠彩色玻璃片 + 水珠 + 闪光微粒的壁纸。

## 第六轮：背景要流动、可互动、有光效变化（2026-10-04）
- 用户要求：背景要动起来、流动起来，有互动/交互效果，包括光效的变化；到 GitHub 上找合适的实现。
- 候选（均本地跑过原版 demo 并录屏，再接到珊瑚红液态玻璃首页上录屏）：
  - 1 流体光晕：PavelDoGreat/WebGL-Fluid-Simulation（MIT，a2d2929，2024-11-12）。改为透明叠在流光玻璃上，鼠标悬停即可拖出光迹（原版需按住拖动），带泛光与体积光；配色取当前色板；每 2–3 秒自动飘入一缕。
  - 2 水波折光：sirxemic/jquery.ripples（MIT，e90bd54，2019）。去掉 jQuery 改写为原生；水面下是实时流动的玻璃背景（每帧上传为纹理）；高光方向随鼠标和时间变化；自动落「雨滴」。
  - 3 云海日光：tengbao/vanta CLOUDS（MIT，f8b3519，2023；依赖 three.js r134 MIT）。珊瑚色晚霞，鼠标转动视角、太阳与光晕随之移动。
  - 4 光泽水面：tengbao/vanta WAVES（同上）。三维水面，镜头随鼠标移动，高光在面上滑动；风格偏低多边形。
  - 5 光束渐变：paper-design/shaders（Apache-2.0，43cd68d，npm 0.0.81）MeshGradient + GodRays 叠加，光束源点跟随鼠标，点击时光强脉冲。
  - 6 网格流光：mikhailmogilnikov/mesh-gradient（MIT，83ff215，npm 2.0.2，Stripe / SwiftUI 式网格渐变）。本身无交互，加了自制的鼠标柔光斑和点击光环。
  - 0 流光玻璃：现版自研 shader，作为对照。
- 看过未用：ruucm/shadergradient（R3F/React 依赖重，仓库根目录无 LICENSE 文件，仅子包 package.json 标 MIT）；sa3dany/wave-gradient（MIT，与 6 同为 Stripe 式，重复）。
- 首页 artifact「巴卡巴卡 液态玻璃」版本 5：左侧加「背景方案」0–6 切换（评审用，正式版去掉；手机上在顶部横排），默认打开推荐的 2 号，各库按需懒加载；许可证全文放在 licenses/。对比页 artifact「巴卡巴卡 流动背景」v1：每号依次为原版 demo 录屏、首页录屏、手机静帧。
- 推荐：首选 2 水波折光；备选 1 流体光晕；光效最强为 5 光束渐变。3、4、6 不推荐（理由见对比页）。
- 已知：沙箱为软件渲染，录屏是虚拟时钟逐帧推进；真实设备帧率未测。3、4 依赖 three.js（约 600KB），1、2 为两层 WebGL 叠加，移动端负载最高。
- 是否通过：待评审。
